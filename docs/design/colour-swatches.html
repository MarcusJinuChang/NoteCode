NoteCode ink colours: current vs proposed

Both appearances are drawn on every device (not your system theme). "Dark" shows what PencilKit shows on a dark page for the stored light value: its lightness is flipped, hue and saturation kept. Sizes are real points at 1x: the hotbar's 34×40pt cell. Highlighters are drawn opaque, the text on top; how PaperKit blends a marker is not simulated.

1 · Hotbar swatches

Orange is selected in each row, with today's accent-coloured ring unchanged (it disappears into an orange swatch, as it does now). Proposed: the highlighter as a marker chip, and in dark mode only the hotbar chip made more vibrant: the stored colour's hue, lifted to a lightness and saturation that read on the bar. The ink on the page is still the darker colour in section 4.

5 · A highlighter across a code panel

Modelled, not measured: a stroke drawn across the panel's left edge, as the 1.0 report describes (a colour step at the edge). Light is drawn as multiply, which is what the step suggests; dark as opaque over the code, which is what "hides the code beneath it" suggests. How PaperKit really blends is unconfirmed.
