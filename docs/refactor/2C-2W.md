## T6. No sleeps

**Today.** 53 sleeps or run-loop spins in 28 test files
(`grep -rnE "Task.sleep|RunLoop.(main|current).run|usleep|Thread.sleep" NoteCodeTests`).
The app's debounces they wait for:

| Debounce | Where |
|---|---|
| Syntax highlighting, 20ms | DocumentTextView.swift:662 (`highlightDelay`) |
| Ink save | DrawingSaveScheduler.swift:96 |
| Toast | Shared/Toast.swift:65 |
| Page badge hold | PageDetailView.swift:718 (`badgeHold`) |
| Launch delay | ContentView.swift:178 (`SidebarPlan.launchDelay`) |
| Rating prompt | ContentView.swift:570 |
| Size settle | NoteEditor's `settleDelay` |

**Do.** One `Clock` (or an `any Clock<Duration>` property, `ContinuousClock()`
by default) per debounce, injectable by tests, or an awaitable "settled"
hook where a test only needs to know the work finished
(`highlightingFinished()`, DocumentTextView.swift:698, is one already).
Then replace the sleeps, one file per commit, in two PRs (the app's hooks
first, then the tests). A spin that waits for UIKit layout and nothing of
ours (`RunLoop.main.run` after a window change) may stay, with its reason in
`scripts/lint-allow.txt`; add a `lint-traps.sh` rule 9 counting test sleeps
as a ratchet.

**Acceptance.** No timing changes in the app (the defaults are today's
values). `check.sh` passes three times in a row; Fast's wall time in the PR,
before and after. The sleep count falls to the allow-list.

## T8. Prove the trap tests

**Do.** For each AGENTS.md › Implementation requirements line that has a
test, reintroduce the mistake in a scratch commit, run the test, see it
fail, and revert. Put each failing output in the PR (one line each). Where a
trap has no test, write one:
- reading `.layoutManager` drops the text view to TextKit 1
  (`textLayoutManager` nil afterwards);
- `PKInk.inkType` on eraser ink (`com.apple.ink.eraser`) traps: the test
  checks `InkContent.inkIdentifier` handles it, and `lint-traps.sh` rule 2
  keeps the getter out;
- `Page.drawingData` after a purge (`Page.delete`) is never read;
- the `MarkupOrderedSet` costs: a build with one `append(contentsOf:)` at
  2,000 elements stays under its budget (`PageViewTests.openingCost` is the
  model).

**Acceptance.** Every trap line names its test in the PR's table, and each
was seen to fail. Tests tagged by their folder (T3).
