# empty folder and scans it. Everything not listed stays private.

# One rule per line; blank lines and lines starting with # are ignored.
#   path/        includes every committed file under the folder
#   path         includes that one file
#   !path/       excludes, as above; the last rule that matches a file wins
#   from => to   copies the committed file `from` to `to` in the export
#                (the edition files, until S2 moves them, and the drafts)

# so the S2 layout (Pro/, AppStore/, ProTests/, Config/) can be listed now.

# Pro/, NoteCode/Pro/, AppStore/, ProTests/, server/, docs/release-1.0/,
