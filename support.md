# NoteCode Support

NoteCode is a note-taking app for computer science coursework: Markdown text,
code blocks you can run (with NoteCode Pro), math, and handwriting with Apple
Pencil or a finger, on Letter-sized pages, on iPad and iPhone (the Duo
included).

**Contact:** notecodesupport@gmail.com

Please include your device model, its iOS or iPadOS version and the build
number from
Settings › Help and About › Version.

## Common questions

**Where are my notes stored?**
On your iPad or iPhone only. NoteCode has no sync yet, so deleting the app deletes the
notes. Settings › Notes › Export All Notes… makes a folder of Markdown files
(with a PDF for each note that has ink) to keep elsewhere.

**I deleted a note by mistake.**
Notes you delete wait in Recently Deleted for 30 days (Settings › Notes, or the
row at the foot of the note list). Swipe or hold a note there to restore it.

**Does Run run my code in the app?**
With NoteCode Pro, Run sends the block's code and your input to NoteCode's run
service and Judge0 to be compiled and run, and the result appears in a panel
beside the page. Nothing is executed on your device. It runs C++, C, Java,
Python, JavaScript, Rust and Go; SQL is Copy only. Without Pro, Run shows what
Pro includes. If a run can't happen (the day's 30 runs are used up, or the
service is down), the panel offers *Open on a Site Instead*: Compiler Explorer
receives the code in the link, and Programiz gets it by paste, so paste when
the page opens. Please don't run code that contains passwords or keys. See the
privacy policy for what is kept.

**Why do I see ads, and how do I remove them?**
Readers without NoteCode Pro see banner ads from Google AdMob. Pro (Settings ›
Pro) removes them. In the system's Settings › Privacy & Security › Tracking you
can
stop NoteCode tracking you; ads then stay but are not personalised.

**How do I cancel Pro?**
Subscriptions are managed by Apple: Settings › Pro › Manage Subscription, or
your Apple account's Subscriptions. Cancel at least 24 hours before the renewal
date to avoid the next charge.

**Why didn't a hidden `#` or `**` show?**
Markers are hidden on purpose. The `#` of a heading appears in the margin while
you edit it, and Settings › Writing › Show Markdown can show markers always.

**Can I use my finger to draw?**
Yes: in draw mode, Finger Draws in the toolbar lets a finger ink while two
fingers scroll. Turn it off for Pencil-only drawing.

**Can I open the same note in two windows?**
A note can be open in one window at a time, so two editors never overwrite each
other. The second window shows "Open in Another Window".
